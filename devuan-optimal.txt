Opción 1: zram-tools + script OpenRC manual (la más simple)
1. Instalar:

sudo apt install zram-tools

Esto te da zramctl y el módulo del kernel. 

2. Crear el script de init en /etc/init.d/zramswap:

#!/sbin/openrc-run

depend() {
    need localmount
    after bootmisc
}

start() {
    ebegin "Activando zram swap"
    zramctl /dev/zram0 --size 6G --algorithm zstd
    mkswap /dev/zram0
    swapon /dev/zram0 -p 100
    eend $?
}

stop() {
    ebegin "Desactivando zram swap"
    swapoff /dev/zram0
    zramctl --reset /dev/zram0
    eend $?
}

3. Hacerlo ejecutable y activarlo:

sudo chmod +x /etc/init.d/zramswap
sudo rc-update add zramswap boot
sudo rc-service zramswap start

Opción 2: zram-init (más potente, soporta múltiples dispositivos)
Desde github.com/vaeth/zram-init incluye scripts OpenRC listos. Se configura en /etc/conf.d/zram-init con variables como type0=swap, size0=6144, algo0=zstd, etc. 

Para 12 GB de RAM, 6 GB de zram con zstd es un buen punto de partida. Verifica con:

zramctl
swapon --show

La Opción 1 es la que menos fricción tiene en Devuan.
